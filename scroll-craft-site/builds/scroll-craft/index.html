One job, not two.

Most of this work splits interaction from craft. The motion goes to one pass and the typography to another, and the page arrives with both done to spec and neither done well.

scroll-craft scores them together. Before a section exists it writes the feeling you should have in it and the thing on screen that causes it. Then it picks a structure, and the structure forbids things.

Scroll is the only input every visitor already knows how to use.

A headless browser walks the finished page at every scroll position, waits for the playhead to settle, and reports what the eye would have missed: dead scroll, cues that never reach full opacity, contrast measured on the composited page, a clip that silently never decoded.

Eight grammars.

One is chosen before anything is built. Each one forbids what the others require, so two builds cannot quietly converge.

Filmic
one-shot

Forbids visible sequence. No chapter numbers, no index, no progress readout.

Chaptered
editorial

Forbids the full-bleed scrub hero. Media never bleeds under type.

Live
surface

Forbids marketing chrome. No wordmark and CTA bar, no display-scale heading.

Continuous
world

Forbids section boundaries. The only element in flow is the spacer.

Typographic
poster

Forbids photographic ground, cards, and decorative motion.

Gallery,
catalog

Forbids a single hero claim. Every object takes the same label schema.

Split
stage

Forbids full-bleed anything before the resolve.

Rhythmic
cutlist

Forbids pinning. No act over about 1.4 viewport-heights.

Codex

Copy the complete scroll-craft folder into your project's .agents/skills/ directory, then ask for the skill by name. Keep the references, scripts and engine with it.

Runtime
Node 18 or newer, for every script in the folder
Encoding
A full ffmpeg build, so clips scrub instead of play. The preflight finds one or names what is missing
Verification
playwright-core and Chrome, installed in the build folder, for the scroll pass
Imagery
Optional key, and only if you want assets generated. Your own photos and footage cost nothing

Stated limits

It has only ever been run on Windows. Generated video is a real spend. And it is opinionated on purpose: it will refuse the layouts that make AI pages recognisable, and it will argue with you about your peak.
