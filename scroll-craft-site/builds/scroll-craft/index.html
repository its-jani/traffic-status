Peripheral, not another window.

traffic-status is a frameless, transparent window that floats above your work and shows one of three lights. It never takes focus, never appears in the taskbar, and never asks you to switch to it.

It is native: eframe and egui draw the window, tokio runs the daemon behind it. No browser engine, no tray icon, no idle CPU cost worth measuring. A hook in your agent writes the state over a loopback call and the light changes.

A glance is cheaper than a context switch.

Green means it finished and is waiting for you. Yellow means it is still going: generating, running a tool, holding a command open. Red means it stopped and wants a decision, a permission, or a fix. The light is the whole interface; the message is only in the tooltip.

What it is

A capsule window, 86 by 236 pixels for one session and 118 by 236 for several, parked 28 pixels from the top-right corner and draggable anywhere.

A Rust binary: eframe and egui for the window, a tokio runtime for the loopback server, serde for the payloads. The widget draws itself with no taskbar entry and no console. Every state change is a POST with a JSON body, capped at 64 KB, rejected with 405 if it arrives as a GET.

Two ways in.

npm / npx

npx traffic-status@latest install --global

Needs Node 18 or newer. The launcher drops the prebuilt binary into %LOCALAPPDATA%\traffic-status\bin and writes every hook it finds.

PowerShell

irm https://raw.githubusercontent.com/its-jani/traffic-status/main/install.ps1 | iex

No Node, no Rust toolchain. Fetches the release asset from GitHub and verifies its SHA-256 before writing a single file.

Platform
Windows 10 or 11, x64. Nothing else is built
Daemon
A background process with no console and no taskbar entry; it starts on the first /traffic on and dies on /traffic off
IPC
HTTP on 127.0.0.1:8765. POST with a JSON body for every change, 64 KB ceiling, GET refused
Uninstall
Removes only files carrying the generated-by: traffic-status marker, so your own commands and plugins survive
Cost
MIT licensed, no paid services, no accounts, no network calls

Stated limits

Windows only, x64 only. The standalone binary is unsigned, so SmartScreen may ask once. If another process holds port 8765, set TRAFFIC_STATUS_PORT. And it shows the current state, not the history: there is no log of what your agent did.
